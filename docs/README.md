operated, and extended.

| Document | Audience | Contents |
| --- | --- | --- |
| [Architecture](architecture.md) | Architects and platform engineers | Components, trust boundaries, data flow, state, secrets, and security controls |
| [Workflow reference](workflows.md) | Operators and reviewers | Triggers, jobs, permissions, gates, and outcomes for every workflow |
| [Tool reference](tools.md) | Maintainers and developers | Python and shell tool interfaces, outputs, and failure modes |
| [Operations and promotion](operations.md) | Operators and application teams | Client lifecycle, promotion, reruns, recovery, and current limitations |
